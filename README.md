# Curso-BackEnd

API desenvolvida em .NET para dar suporte à aplicação de cursos online.
Responsável por autenticação, controle de acesso e comunicação com banco de dados.

Este projeto foi construído com foco em prática de backend, organização de arquitetura e integração com frontend.

---

## 📌 Objetivo

Aplicar conceitos fundamentais de desenvolvimento backend:

* Estruturação de API REST
* Autenticação
* Integração com banco de dados relacional
* Organização de camadas
* Separação de responsabilidades

Projeto voltado exclusivamente para prática técnica.

---

## 🛠 Tecnologias Utilizadas

* C#
* .NET
* ASP.NET
* PostgreSQL

---

## 🚀 Funcionalidades

* Rotas de autenticação
* Comunicação com banco de dados PostgreSQL
* Estruturação de endpoints REST
* Integração com aplicação frontend
* Controle básico de acesso

---

## 🔗 Integração

Este backend está vinculado ao frontend:

[https://github.com/Apolo0013/Curso-FrontENd](https://github.com/Apolo0013/Curso-FrontENd)

Ambos os repositórios funcionam em conjunto para simular uma plataforma de cursos com autenticação e acesso controlado.

---

## 🧠 Conceitos Aplicados

* Estrutura de controllers
* Conexão com banco de dados
* Organização por camadas
* Separação entre regras de negócio e acesso a dados
* Estruturação de respostas HTTP

---

## ▶ Como Executar

1. Clonar o repositório
2. Configurar a string de conexão com PostgreSQL
3. Executar a aplicação com o comando padrão do .NET para rodar projetos ASP.NET

A aplicação roda localmente e deve estar ativa para que o frontend funcione corretamente.
